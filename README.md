# Storage Estimator - Main Version

## Purpose
A small Python program from CS-117 Lab 10. You enter a storage size in gigabytes (GB) and it converts it to megabytes (MB), kilobytes (KB) and bytes, using 1 GB = 1024 MB, 1 MB = 1024 KB and 1 KB = 1024 bytes.

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

```
python storage_estimator.py
```

4. Type a size in GB and press Enter.

## Example
Input:

```
Enter storage in GB: 2
```

Output:

```
--- Storage Estimate ---
Storage in MB: 2,048.00
Storage in KB: 2,097,152.00
Storage in bytes: 2,147,483,648
```
